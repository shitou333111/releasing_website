# TTS 脚本使用指南

## 正在使用的 TTS 脚本（位于 docs/.vitepress/script/）

### 1. gen-tts-assets.js
**功能**：TTS 资源生成的核心脚本，负责从 Markdown 文件提取文本、调用 MiMo API 合成音频并生成时间轴数据。

**使用方法**：
```bash
# 生成默认文章的 TTS 资源
npm run gen-tts-assets

# 生成指定文章的 TTS 资源
node docs/.vitepress/script/gen-tts-assets.js --article 书/决定自由

# 生成所有启用 readAloudEnabled 的文章
node docs/.vitepress/script/gen-tts-assets.js --all

# 强制重新生成（忽略缓存）
node docs/.vitepress/script/gen-tts-assets.js --force
```

**环境变量配置**：
- `MIMO_API_KEY`：MiMo API 密钥（必需）
- `MIMO_TTS_MODEL`：TTS 模型名称（默认：mimo-v2-tts）
- `MIMO_TTS_VOICE`：语音类型（默认：mimo_default）
- `MIMO_TTS_STYLE`：朗读风格（默认：温暖 平和 宁静 沉稳）
- `MIMO_TTS_TEMPERATURE`：温度参数（默认：0.3）
- `MIMO_TTS_TOP_P`：top_p 参数（默认：0.5）

---

### 2. gen-tts-chunked.js
**功能**：TTS 分块合成脚本，支持大文本分段处理和 MFA 对齐。将文本分块合成音频、处理音频缓存、支持 MFA 语音对齐。

**使用方法**：
```bash
# 生成指定文章的分块 TTS 并自动运行 MFA 对齐
node docs/.vitepress/script/gen-tts-chunked.js 书/决定自由.md

# 指定 .md 文件路径
node docs/.vitepress/script/gen-tts-chunked.js path/to/article.md

# 强制重新生成
node docs/.vitepress/script/gen-tts-chunked.js --force

# 跳过 MFA 对齐步骤
node docs/.vitepress/script/gen-tts-chunked.js --skip-mfa
```

**工作流程**：
1. 解析 Markdown 提取段落文本
2. 将长文本按字符数限制分块（默认 1000 字符/块）
3. 调用 MiMo TTS API 合成每个块的音频
4. 自动运行 MFA 对齐（gen-tts-align-mfa.py）
5. 后处理未对齐的时间轴（postprocess-unaligned-cues.cjs）
6. 合并段落和时间轴数据（merge-segments-and-cues.cjs）
7. 生成最终文件：final.wav, cues.json, segments.json

**环境变量配置**：
- `TTS_CHUNK_MAX_CHARS`：每块最大字符数（默认：1000）
- `TTS_CONCURRENCY`：并发合成数量（默认：8）
- `MFA_DICT`：MFA 字典名称（默认：mandarin_china_mfa）
- `MFA_ACOUSTIC`：MFA 声学模型（默认：mandarin_mfa）
- `SKIP_MFA`：设置为 "1" 可跳过 MFA 对齐

---

### 3. gen-tts-align-mfa.py
**功能**：Montreal Forced Aligner (MFA) 对齐工具。准备语料库、运行 MFA 对齐、将 TextGrid 结果转换为 JSON 时间轴。

**使用方法**：
```bash
# 运行 MFA 对齐（通常由 gen-tts-chunked.js 自动调用）
python docs/.vitepress/script/gen-tts-align-mfa.py \
  --dir docs/public/tts/书/决定自由 \
  --dict mandarin_china_mfa \
  --acoustic mandarin_mfa \
  --conda-env mfa \
  --mfa-opts "--clean --jobs 4"

# 仅转换现有 TextGrid 文件（繁体转简体）
python docs/.vitepress/script/gen-tts-align-mfa.py \
  --dir docs/public/tts/书/决定自由 \
  --convert-textgrids-only

# 保留临时目录用于调试
python docs/.vitepress/script/gen-tts-align-mfa.py \
  --dir docs/public/tts/书/决定自由 \
  --dict mandarin_china_mfa \
  --acoustic mandarin_mfa \
  --keep-tmp
```

**依赖要求**：
- Montreal Forced Aligner CLI（已安装并在 PATH 中）
- Python 包：textgrid（`pip install textgrid`）
- Conda 环境：mfa（或通过 --conda-env 指定）

**输出文件**：
- `cues.mfa.json`：包含每个段落的对齐时间信息
- `mfa_output/*.TextGrid`：MFA 生成的 TextGrid 文件
- `mfa_corpus/*.lab`：用于 MFA 的转录文件

---

### 4. postprocess-unaligned-cues.cjs
**功能**：后处理未对齐的时间轴标记。将 chunk 本地时间转换为绝对时间，为未对齐的段落分配估算时间。

**使用方法**：
```bash
# 后处理指定文章的对齐结果（通常由 gen-tts-chunked.js 自动调用）
node docs/.vitepress/script/postprocess-unaligned-cues.cjs 书/决定自由

# 使用绝对路径
node docs/.vitepress/script/postprocess-unaligned-cues.cjs C:/path/to/tts/output/dir
```

**输入/输出**：
- 输入：`cues.mfa.json`
- 输出：`cues.mfa.postproc.json`

---

### 5. merge-segments-and-cues.cjs
**功能**：合并段落信息和时间轴数据。将 segments.chunked.json 与 cues.mfa.postproc.json 合并为最终的 cues.json。

**使用方法**：
```bash
# 合并指定文章的数据（通常由 gen-tts-chunked.js 自动调用）
node docs/.vitepress/script/merge-segments-and-cues.cjs 书/决定自由

# 使用绝对路径
node docs/.vitepress/script/merge-segments-and-cues.cjs C:/path/to/tts/output/dir
```

**输入/输出**：
- 输入：`segments.chunked.json`, `cues.mfa.postproc.json`
- 输出：`cues.json`（前端使用的最终时间轴文件）

---

### 6. readAloudText.js
**功能**：TTS 文本处理的共享工具函数库。提供文本清洗、指纹生成、空白字符规范化和文本分块功能。

**导出的函数**：
- `cleanTextForTTS(input)`：清洗文本用于 TTS（去除 HTML 标签、脚注等）
- `createStableFingerprint(input)`：生成稳定的 FNV-1a 指纹哈希
- `normalizeWhitespace(input)`：规范化空白字符
- `splitTTSChunks(input, maxChars)`：将长文本智能分块（在标点处断开）
- `removeCircledFootnotes(input)`：移除带圈脚注符号
- `stripInlineHtml(input)`：移除内联 HTML 标签

**使用方式**：
```javascript
import {
  cleanTextForTTS,
  createStableFingerprint,
  normalizeWhitespace,
  splitTTSChunks
} from './readAloudText.js';
```

## 完整工作流程示例

### 方式一：使用 gen-tts-assets.js（推荐）
```bash
npm run gen-tts-assets
```

### 方式二：使用 gen-tts-chunked.js（需要 MFA 对齐时）
```bash
node docs/.vitepress/script/gen-tts-chunked.js 书/决定自由.md
```

### 手动逐步执行（调试用）
```bash
# 1. 生成 TTS 音频和时间轴
node docs/.vitepress/script/gen-tts-chunked.js 书/决定自由.md --skip-mfa

# 2. 运行 MFA 对齐
python docs/.vitepress/script/gen-tts-align-mfa.py \
  --dir docs/public/tts/书/决定自由 \
  --dict mandarin_china_mfa \
  --acoustic mandarin_mfa

# 3. 后处理未对齐的时间轴
node docs/.vitepress/script/postprocess-unaligned-cues.cjs 书/决定自由

# 4. 合并最终数据
node docs/.vitepress/script/merge-segments-and-cues.cjs 书/决定自由
```

## 输出文件说明

对于每篇文章（如 `书/决定自由`），TTS 系统会在 `docs/public/tts/书/决定自由/` 目录下生成：

- **final.wav**：完整的合成音频文件
- **cues.json**：段落级时间轴（前端朗读组件使用）
- **segments.json**：段落文本和元数据
- **manifest.json**：全局索引文件（位于 docs/public/tts/）
- **chunk-*.orig.wav**：各个分块的原始音频（中间文件）
- **cues.mfa.json / cues.mfa.postproc.json**：MFA 对齐中间结果

## 注意事项

1. **API 密钥**：必须设置 `MIMO_API_KEY` 环境变量才能调用 MiMo TTS API
2. **缓存机制**：gen-tts-assets.js 支持缓存已合成的段落，避免重复调用 API
3. **MFA 要求**：使用 MFA 对齐需要安装 Montreal Forced Aligner 和 Python textgrid 包
4. **并发控制**：可通过 `TTS_CONCURRENCY` 环境变量调整并发请求数
5. **字符限制**：MiMo v2 TTS 支持最大约 6000 字符/请求，其他模型约 260 字符
